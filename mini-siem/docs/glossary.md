# Glossary (DRAFT for Ramon to rewrite in his own words)

> At least 8 terms, 1-2 sentences each, understandable for a classmate from another field.

- **Log**: a file or stream of lines where a system records what happened and when.
- **SIEM**: Security Information and Event Management, a tool that collects logs from many places, searches them and raises alerts.
- **Event**: one thing that happened, for example a login, a failed login or a file access.
- **Alert**: a warning the system creates when events match a rule.
- **Brute force**: guessing passwords by trying many of them quickly, which shows up as many failed logins from one source.
- **Source IP**: the network address a request came from.
- **Threshold**: the number that triggers an alert, for example 3 failed logins.
- **False positive**: an alert for harmless behaviour, for example a user who mistyped a password twice.
